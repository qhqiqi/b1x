# 冠英 GUANYING · 选型直连页（可交互原型）

不需要构建工具的静态站点：`app/index.html` + `app/styles.css` + `app/app.js`。
本目录整体（`p3/`）放在共享仓库 `qhqiqi/b1x` 下。

目录结构：

```
b1x/                     ← GitHub 共享仓库
├── …                    ← 仓库原有内容（p1 / p2 等，不要动）
└── p3/                  ← 本项目，整体拷入/推入即可
    ├── index.html       ← 入口：自动跳到 ./app/index.html
    ├── app/

    │   └── app.js
    ├── preview/         ← 桌面 / 移动端整页预览
```

打开方式：双击 `p3/index.html`（跳到 `app/index.html`），或直接打开 `p3/app/index.html`。
部署后地址为 `https://qhqiqi.github.io/b1x/p3/`（根路径与 `/p3/` 都会落到 `p3/app/index.html`）。

## 1. 这一页到底在解决什么

它不是一个「公司介绍页」，而是把冠英最有杀伤力的一件事前置：**没有 OE 编码，也能把车型落到型号**。

| 现状卡点 | 页面上的对应设计 |
| --- | --- |
| 型号对不上：无 OE 编码、后市场换桥、同件多码 | 选型工具按「车型 / 车桥 / 尺寸 / 旧片」四路检索，编码是冠英自有编码，不依赖主机厂 |
| 报价慢：日均 10 条询价，一条 2 小时 | 选型结果直接带材质、μ 值、温度、MOQ、交期；「加入询价」把型号带进表单 |
| 现场答不上 | 同一套检索在手机宽度下可用，销售在汽配店当场查 |
| 线索不准：海关数据全是贸易公司 | 表单字段即筛选器（国家、年采购量、车型/车桥），贸易公司自动降权 |

## 2. 页面结构

1. **Hero** — 主张「没有 OE 编码，也能一次选对」，四个硬指标（1500 万套 / 30+ 国家 / 5 品牌 / 4 万组报告）+ 双 CTA。
2. **四个卡点** — 用客户视角的痛点做信任前置，而不是先讲厂房和设备。
3. **选型工具** — 核心交互，演示数据 10 条，四种检索方式。
4. **产品线** — 鼓式 / 盘式 / 风电，各带关键规格，可直接加清单。
5. **品牌矩阵** — 五个品牌，同一产线与配方体系。
6. **合作流程** — 1 分钟 → ≤2 小时 → 当天 → 15–25 天，把「快」写成承诺。
7. **询价表单** — 极简必填三项（公司、国家、联系方式），其余选填。

## 3. 交互说明

- 检索：车型 / 车桥 / 尺寸 / 旧片四种模式，输入框实时匹配；`420x180`、`420×180`、`420 180` 等价。
- 清单：任意「加入询价」→ 顶部计数 + 右侧抽屉，`localStorage` 保留上次选择。
- 表单：必填校验、生成询价单号（`GY-Q-YYYYMMDD-xxx`）、把清单型号写入需求。
- 无障碍：键盘可达、`prefers-reduced-motion` 下关闭动画、表单有 `label` 与错误提示。

## 4. 接真实系统时替换哪里

| 现在（演示） | 生产环境 |
| --- | --- |
| `app/app.js` 里的 `PRODUCTS` 数组 | 产品目录接口，建议 `GET /api/products?q=&mode=`，返回同结构 |
| 前端 `search()` 字符串匹配 | 服务端检索；车桥/车型用同义词表归一（如「457 桥 / 457 后桥 / 457 单减桥」） |
| 表单提交的模拟提示 | 写入孚盟 CRM 的线索表 + 邮件/企微通知外贸团队 |
| 「查看测试报告」 | 关联试验报告编号，按批次返回 PDF 摘要（几万组报告建议按产品+批次建索引） |

建议的数据字段（产品主数据）：

```
code        冠英自有编码
type        鼓式 / 盘式 / 风电
size        摩擦面尺寸
axles[]     适配车桥（含别名）
cars[]      适配车型（含后市场口语写法）
mat / mu / temp
reports[]   试验报告编号
```

OE 编码不建议强行打通，而是建一张「外部编码 → 冠英编码」的映射表，客户报任何一侧都能落到同一行。

## 5. 上线前要替换的占位内容

- 邮箱 `export@guanying.example`、WhatsApp `+86 000 0000 0000`
- 五个品牌名（当前为占位示意：GUANYING / ROADFORCE / TERRA / WINDMAX / APEX）
- 产品参数、交期、MOQ 需按真实目录核对
- 公司资质、厂房与产线照片
- 页脚版权与备案信息

## 6. 建议的下一步

1. **英文 / 西语版**：外贸客户占比高，至少做 EN；阿语可先行 RTL 布局预留。
2. **报价单 PDF**：选型结果一键导出带 logo 的报价单，替代手工 Excel。
3. **PWA + 离线缓存**：汽配店信号差，型号库可离线查。
4. **埋点**：检索关键词、命中率、加清单率、表单转化——用来反推目录缺哪些型号。

## 7. 验收自测

已用无头 Chrome 跑过：

- 初始 10 条；「457 桥」→ 1 条；「420x180」→ 1 条；「J6」→ 1 条；无效词 → 空状态
- 加入清单 → 计数 1、按钮变「已加入」、localStorage 写入
- 抽屉打开 / 关闭、清单移除
- 空表单提交 → 3 个字段标红 + 错误提示
- 完整提交 → 生成 `GY-Q-` 单号
- 「看旧片」模式 → 上传占位卡

## 8. 放进 b1x 并开启 Pages

1. 在 `qhqiqi/b1x` 仓库里新建目录 `p3/`，把本目录的内容放进去（`p3/index.html` + `p3/app/` + `p3/preview/`）。
2. 仓库 Settings → Pages → Source 选 **Deploy from a branch**，分支 `main`，目录 `/ (root)`。
3. 访问 `https://qhqiqi.github.io/b1x/p3/`（或 `/b1x/` 根路径，若根 index 也放跳板）。

如果改了 `app/` 里的资源，记得同步刷新 `p3/index.html` 的跳转目标（当前是 `./app/index.html`）。
