# 冠英 GUANYING · 选型与询价页面

直接打开 `index.html` 即可使用，无需构建或联网加载字体、图片。

## 2026-11-21 页面优化

- 保留橙黑品牌识别，调整首屏、导航、字号、留白与产品卡片。
- 首屏搜索和示例链接进入 `match.html?q=...`；选型演示紧随首屏。
- 320px–桌面响应式规则，900px 以下折叠菜单；减少动态效果偏好生效。
- 本地 SVG 绘制制动部件材质示意，无网络图片依赖。图形并非实物照片或尺寸图。
- 搜索支持车型、车桥、编码、尺寸以及混合条件。
- 修复筛选重绘后「已加入」状态丢失；产品卡和结果卡共享清单状态。
- 清单保存在 localStorage；不可用时仍支持当前页面内使用。
- 询价抽屉支持焦点约束、Escape 关闭、关闭后焦点恢复及背景滚动锁定。
- 选型 Tab 支持方向键、Home / End；表单支持必填错误聚焦和无障碍说明。
- 旧片图片支持本地预览，允许 10 MB 以内 JPG / PNG / WebP，不会上传或识别。
- 表单生成 UTF-8 文本询价草稿，用户主动点击下载；不会发送，也不清空清单。
- 生成草稿时刷新清单型号，移除的型号不会残留在自动生成的「型号：」行中。
- 删除未接通服务的成功提交提示，检测资料及报价采用待确认口径。

## 文件与接口

`index.html`、`styles.css`、`premium.css`、`app.js` 为优化后的首页；`assets/` 保存本地 SVG 插画。
实时查询页通过 `match-premium.css` 统一视觉；`match.css`、`match.js`、`samples.js` 以及原实时匹配接口和离线示例逻辑保留。
目录入口和 P2 数据契约未改动。正式价格、适配、MOQ、交期均需业务确认。

首页 `PRODUCTS` 的 10 条为演示数据；真实匹配入口请使用实时查询页。
联系方式和品牌矩阵仍有占位内容，正式发布前应替换为真实资料。
后续接入后台时，将 `submitQuote` 替换为真实提交，并在服务端确认成功后显示回执。
本次仅生成文本草稿，不包含图片附件。
