# P1 可直接搬进 PPT 的 8 页（数字 + 口播 + 出处）

> 每页给：**标题**（照抄可用）、**要点**（PPT 上就写这几行）、**口播一句**、**出处**（评委不信时翻给他看）。
> 所有数字都能用命令复现，别改小数。

---

## S1 封面

**冠英 SELECT——3 秒选型，每个答案都能翻到册子那一页**

- 输入：客户怎么说就怎么报（车型 / 车桥 / 编码 / 三个尺寸 / 外商码）
- 输出：3 个方案 + 置信度 + 册子页码
- 时延：3–6 毫秒，纯本地规则，不联网、不调大模型

**口播**：我们做的不是搜索框，是销售的判断外挂。

---

## S2 痛点（为什么这事值得做）

**客户不会说产品册上的名字**

- 客户说「J6P 后轮」，册子上写「解放J6」；说「汉德 35 吨桥」，册子上是「汉德-35T」
- 国内靠中文名还能碰运气，**海外同一片刹车蹄，在美洲叫 FMSI 4524，在欧洲按 SAF 尺寸报 419×178**
- 车桥换代就换号；报错一片 = 赔一副运费 + 丢一次信任

**口播**：销售每天在猜，猜错的成本是运费和信任，不是流量。

---

**4 本官方产品册 → 217 个型号 + 34 条出口对码**

| 做了什么 | 数字 |

| 车桥字典 | 7 个（新457、汉德-35T、沃胜-11.5T、湖-54Q、索马…） |
| 口语别名表 | 25 条（J6P→解放J6、EST→欧曼、富华→富华桥…） |

**口播**：全部来自客户给的册子，没有爬任何网站。

## S4 怎么用（放一张界面图）

**一句话进来，三张卡出去**

1. 卡片：型号 + 尺寸原文（147×100×14.5/16.5）+ 置信度（高/中/低）
2. 出处：kooying 产品册 第 28 页，点开就是原页
3. 报价：**恒为「询价确认」**——资料包没有价格，我们不编

**口播**：淘宝给你 200 个结果让你挑；我们给你 3 个，每个带证据。

**界面**：本地起服务后打开 http://127.0.0.1:8787/（可直接演示或截图）

**127/127 + 49 条人工核对 + 42/42 演示路径**

| 证据 | 数字 |

| 文字层逐条机器复核 | **127/127** 与原文一致 |

| 扫描图页抽检 | **12/12** 一致 |

**口播**：证据在纸上，不在我们嘴里——随便点一条，翻到原页。

## S6 老板点的重点：海外客户

**外商报的不是中文车型，是码**

| 外商说法 | 我们说 |
|---|---|
| FMSI 4524 / OE A3222E1383 | → **4524Q**，出口册第 32 页 |
| BPW 420×180 / WVA 19032 | → **BPW180**，第 33 页 |
| SAF 420×178 / OE 15025412 | → **SMB178**，第 34 页 |

- 出口册 p32–34 原本是**图片**（转曲页），我们 OCR 重建了这三张「码对码」表
- **10/34 条已人工对原页核对**，海外评测 **8/8**

**口播**：外商记的是他国家的号，我们做的是把这个号翻译成我们的型号。

---

## S7 边界（主动说，比被问穿强）

**三种我们答不了，但都有接法**

1. **要测试报告原件** → 没有，不编；改说检测能力：2 台克劳斯 + 4 台定速机，14 项指标对照（400℃ 失重比同行低 12%）
2. **要报价** → 恒为「询价确认」
3. **冷门车桥（斯堪尼亚 / BPW 适配）** → 系统追问，不硬凑

**还有一个断点要承认**：出口型号（4524Q）↔ 国内型号没有对照表（0/34），要客户补一张两列表。

**口播**：我们把查不到的写成了追问，而不是写成「大概这个」。
