## 2. 两个页面在干什么

| 页面 | 用途 | 说明 |
|---|---|---|
| `app/index.html` | 对外落地页 / 演示门面 | 车型·车桥·尺寸·旧片四路演示选型 + 询价清单 + 询价表单（演示数据，`app.js` 里 `PRODUCTS`） |
| `app/match.html` | **真数据查询页** | 接 P2 引擎，按 `p3_handoff.md` 第 3 节的字段规则渲染 |

`match.html` 的渲染规则（别自己拼字符串）：

- 型号标题 = `sku_id`；置信度徽章 = `confidence`（高/中/低）
- 一句话说明 = `reason`；尺寸 = `dims.raw_text`（原文含备选厚度，不自己拼）
- 出处 = `evidence[0].report_id` + `page`；展开「为什么是这个」显示 `snippet`
- 报价 = `price`，为 `null` 一律「询价确认」
- `verified=false` 只显示「未核对」，不说可溯源；`ocr=true` 加「扫描图页识别」
- `mode=ask` 只渲染追问，不给候选；`mode=export` 渲染对码卡（外商码 → 我方型号 → 册子页码）
