## 3.5 尺寸口径（重要，别再写错）

产品册表头原文：中文「外弧*宽度*厚度 孔数」、英文「outer arch / width / thickness」。
所以 `dims.arc_mm` = 外弧，`dims.width_mm` = 宽度，`dims.thickness_mm` = 厚度。
**没有"长度"这个字段**——v1.1 的"宽×长×厚"是误读，v1.2 已更正。
